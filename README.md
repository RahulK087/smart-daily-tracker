# Smart Daily Tracker

A full-stack productivity and expense management web application built using Spring Boot, MySQL, Thymeleaf, Bootstrap, and REST APIs.

---

## Features

- User Login & Signup
- Continue Without Account
- Task Management System
- Add / Edit / Delete Tasks
- Mark Tasks as Completed
- Task Priority & Scheduling
- Expense Tracking
- Category-wise Expense Analytics
- Monthly Budget Tracking
- Dashboard Insights & Charts
- Responsive UI Design
- Cloud Database Integration

1. User enters dashboard
2. Manages daily tasks
3. Tracks expenses
4. Monitors category budgets
5. Views productivity analytics
6. Analyzes expense insights
